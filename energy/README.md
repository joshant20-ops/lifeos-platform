# LifeOS Energy

LifeOS Energy Intelligence application.

## Planned capabilities

- Octopus Energy tariff and event intelligence
- Enphase monitoring
- Solar and battery forecasting
- Import/export optimisation
- Home Assistant integration
- LifeOS governance integration

## Architecture

- Engineer proposes structural changes
- Watchman validates execution
- Executor performs bounded actions
- Auditor verifies results
- Workers communicate through files, queues and state only
